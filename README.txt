SEOUL STORIES — K-DRAMA INSPIRED STORYBOOK WEBSITE

How to run:
1. Extract this ZIP file.
2. Open the seoul_stories_kdrama folder.
3. Double-click index.html to open it in Chrome or another browser.

The website contains 30 K-drama stories, each with one chapter.
The project uses semantic HTML in index.html, an external stylesheet (styles.css),
an external JavaScript file (app.js), and local artwork in the images folder.
Each story uses its supplied drama poster image (poster-01.jpg through
poster-30.jpg) in title order.

The website works offline. Use the navigation controls to return to the library,
move between stories, change the color theme, and track reading progress.
